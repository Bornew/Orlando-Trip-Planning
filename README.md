# Orlando Trip Planning

Chinese itinerary for three travelers visiting Orlando, December 4–12, 2026.

- Planned public site: https://bornew.github.io/Orlando-Trip-Planning/
- [Markdown itinerary](orlando_trip_cn_2026-12-04_12-12.md)
- [Original HTML itinerary](orlando_mobile_trip_cn.html)

`index.html` is the GitHub Pages entry point and matches `orlando_mobile_trip_cn.html`.
The HTML embeds all 40 project photos so it works as a standalone file. The Markdown uses images from `assets/photos/`; include that folder when sharing or publishing it. Photo captions link to their sources.

Run `python3 tools/build_trip_html.py` to refresh the Markdown photo sections and both HTML files. The builder uses `data/project_photos.json` and the bundled theme files in `tools/`. No external template or Python packages are required.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**.
The site URL becomes available after GitHub completes the Pages build.

Accommodation is tentative. Ticket prices and availability are dated snapshots; check the linked providers before booking.
